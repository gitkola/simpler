- `requestClarification`:

- `sendModelFeedback`:
  - При аналізі вимог - для вказівки на потенційні проблеми чи протиріччя

- `updateProjectState`:
  - Спочатку - для збереження зібраних вимог
  - Під час розробки - для оновлення статусів задач та коду
  - Постійно - для підтримки актуальності всієї інформації про проєкт

Тобто ці функції - це універсальні інструменти комунікації та управління станом проєкту, які важливі на всіх етапах. У новому чаті ми можемо зосередитись на алгоритмі опитування, але з розумінням, що використовуємо вже відпрацьовані механізми взаємодії.
